## 🔬 Top Wafer Fab Scheduling Tools Ecosystem & Semiconductor Manufacturing Software
**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Semiconductor Fab Scheduling, Advanced Planning & Scheduling (APS), Dispatching, WIP Management & Manufacturing Execution Systems (MES)*  
**Last updated: August 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Wafer Fab Scheduling Tools**. These systems handle finite-capacity scheduling, real-time dispatching, WIP tracking, tool utilization optimization, automated material handling system (AMHS) routing, and constraint-based planning across complex semiconductor manufacturing flows (lot, batch, reticle, AMHS, and process constraints).

**Examples** include Applied SmartFactory, Siemens Opcenter APS, Critical Manufacturing, Flexciton, CamLine InFrame Synapse, FactoryLogix, 42Q, Parsec TrakSYS, Asprova APS, and PlanetTogether (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom constraint solvers, reinforcement-learning dispatchers, fab simulators, and open APS engines — ideal for semiconductor manufacturers, researchers, and developers building transparent, adaptable fab scheduling solutions.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## 💻 Open-Source GitHub Projects
*Sorted descending by repository star count.*

- **[Odoo Community](https://github.com/odoo/odoo)** [<img src="https://img.shields.io/github/stars/odoo/odoo?style=social&color=white" alt="Odoo Stars"/>](https://github.com/odoo/odoo/stargazers) 📦  
  Comprehensive open-source enterprise suite featuring advanced Manufacturing Resource Planning (MRP), Work Center capacity scheduling, and shop-floor control modules.

- **[ERPNext](https://github.com/frappe/erpnext)** [<img src="https://img.shields.io/github/stars/frappe/erpnext?style=social&color=white" alt="ERPNext Stars"/>](https://github.com/frappe/erpnext/stargazers) 💼  
  Modern open-source ERP & MRP system with integrated production planning, multi-level BOM management, operation routing, and job card scheduling.

- **[OptaPlanner / Timefold Solver](https://github.com/TimefoldAI/timefold-solver)** [<img src="https://img.shields.io/github/stars/TimefoldAI/timefold-solver?style=social&color=white" alt="Timefold Solver Stars"/>](https://github.com/TimefoldAI/timefold-solver/stargazers) 🧠  
  Powerful open-source constraint solver (successor to OptaPlanner) widely used for job-shop, resource allocation, and complex wafer fab production scheduling problems.

- **[qcadoo MES](https://github.com/qcadoo/mes)** [<img src="https://img.shields.io/github/stars/qcadoo/mes?style=social&color=white" alt="qcadoo MES Stars"/>](https://github.com/qcadoo/mes/stargazers) 🏭  
  Friendly open-source web MES for production management including finite scheduling, lot tracking, machine parameters, and shop-floor execution features.

- **[frePPLe](https://github.com/frePPLe/frepple)** [<img src="https://img.shields.io/github/stars/frePPLe/frepple?style=social&color=white" alt="frePPLe Stars"/>](https://github.com/frePPLe/frepple/stargazers) 🎯  
  Leading open-source advanced planning and scheduling (APS) system with finite-capacity planning, multi-level BOMs, material constraints, and REST API integration.

- **[free-mes](https://github.com/metaxk-company/free-mes)** [<img src="https://img.shields.io/github/stars/metaxk-company/free-mes?style=social&color=white" alt="free-mes Stars"/>](https://github.com/metaxk-company/free-mes/stargazers) 🛠️  
  Open-source Manufacturing Execution System with production scheduling, order management, task dispatching, and real-time operational dashboards.

- **[SAMPO](https://github.com/aimclub/SAMPO)** [<img src="https://img.shields.io/github/stars/aimclub/SAMPO?style=social&color=white" alt="SAMPO Stars"/>](https://github.com/aimclub/SAMPO/stargazers) 🔬  
  Open-source framework for adaptive manufacturing process scheduling using meta-heuristics, genetic algorithms, and multi-agent simulation methods.

- **[PySCFabSim](https://prosysscience.github.io/PySCFabSim-release/)** [<img src="https://img.shields.io/github/stars/prosysscience/PySCFabSim-release?style=social&color=white" alt="PySCFabSim Stars"/>](https://github.com/prosysscience/PySCFabSim-release/stargazers) 🧪  
  High-performance open-source semiconductor fab simulator built for AI dispatching, planning algorithm research, and large-scale wafer fab experiments.

- **[RL4SemiconductorFabSched](https://github.com/ingambe/rl4semiconductorfabsched)** [<img src="https://img.shields.io/github/stars/ingambe/rl4semiconductorfabsched?style=social&color=white" alt="RL4SemiconductorFabSched Stars"/>](https://github.com/ingambe/rl4semiconductorfabsched/stargazers) 🤖  
  Semiconductor fab scheduling research codebase using self-supervised and reinforcement learning for dispatching policy optimization.

  Simulation and modeling tools for automated material handling systems (AMHS) and overhead hoist transport (OHT) traffic in modern semiconductor fabs.

- **[OpenI40 Platform](https://github.com/openi40/OpenI40Platform)** [<img src="https://img.shields.io/github/stars/openi40/OpenI40Platform?style=social&color=white" alt="OpenI40 Platform Stars"/>](https://github.com/openi40/OpenI40Platform/stargazers) 🌐  
  Open-source advanced production scheduler designed for Industry 4.0 with modular scheduling, MES components, and manufacturing constraints.

- **[U-APS](https://github.com/iyulab/U-APS-releases)** [<img src="https://img.shields.io/github/stars/iyulab/U-APS-releases?style=social&color=white" alt="U-APS Stars"/>](https://github.com/iyulab/U-APS-releases/stargazers) ⚡  
  Hybrid Rust/C# advanced production scheduling system combining optimization algorithms with practical industrial input/output formats.

### 💡 Additional Strong Open-Source Options
- Community **job-shop / flexible job-shop solvers**, **genetic programming dispatchers**, and **fab simulation environments**.
- Academic **semiconductor scheduling benchmarks**, **AMHS traffic models**, and **reinforcement-learning fab environments**.
- Many **constraint programming** and **OR-Tools / HiGHS** based custom APS prototypes on GitHub.

**Frameworks for building custom systems**: Combine **frePPLe** or **Timefold Solver** for core scheduling, **PySCFabSim** for high-fidelity fab simulation, **OptaPlanner/Timefold** for constraint modeling, **PostgreSQL + dbt** for manufacturing data, **Grafana** for real-time visibility, and **Ollama** or local LLMs for intelligent dispatch assistants and what-if scenario generation.

## ⚠️ Disclaimer
- This is a **community-curated** list — not exhaustive and not an official endorsement.

- Self-hosted open-source solutions require proper validation, security, data integrity, and integration testing before production deployment in a cleanroom fab environment.
